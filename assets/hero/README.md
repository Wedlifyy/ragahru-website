# assets/hero/

Masthead artwork, set in `config/site-config.js`:

- `rail/` — posters for the three drifting rows behind the headline (`heroRail`)
- `posters/` — the three phone screens (`heroPhonePosters`)

`hero.mp4` and `hero-poster.jpg` are from the earlier background-film masthead
and are no longer used. They can be deleted; `hero.mp4` alone is 3.7 MB.
